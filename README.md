# 자막 없이 일본어

아이돌 영상에서 자주 들리는 생활 일본어를 단어장, 플래시카드, 퀴즈로 익히는 개인용 학습 페이지.

- `index.html`: 페이지 전체. 표현 데이터는 스크립트 안의 `RAW`에 있다.
  - 한 줄 형식: `[일본어, 읽기(가나), 한글 발음, 뜻, 메모, 예문, 예문 해석]`
  - 카테고리와 단계는 `CATS`, `LEVELS`.
- `a/`: 표현·예문 녹음. 파일 이름은 읽을 문장의 해시라서 직접 고치지 않는다.
- `tools/check.sh`: 문법, 데이터 형식, 중복 검사.
- `tools/make-audio.sh`: 빠진 녹음을 만들고 안 쓰는 녹음을 지운다 (macOS Kyoko 음성, ffmpeg 필요).

표현을 고친 뒤에는 `tools/check.sh && tools/make-audio.sh`를 돌리고 커밋하면 GitHub Pages에 반영된다.
